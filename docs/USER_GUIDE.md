# PERSONA 90: Poori User Guide

**Website:** https://persona-90.vercel.app · **Price:** Free · **Kaam karta hai:** Computer, Android, iPhone (browser mein, ya "app" ki tarah install karke)

PERSONA 90 ek 90 din ka personal-development programme hai. Roz sirf ~30 minute mein aap 10 skills par kaam karte ho:

| Skill | Matlab |
|---|---|
| Self-confidence | Apne faisle par bharosa, bina baar-baar poochhe |
| Communication | Saaf bolna, achhe se sunna |
| Decision-making | Time par, soch-samajh kar faisla lena |
| Emotional intelligence | Apni aur doosron ki feelings samajhna |
| Social intelligence | Logon aur situations ko padhna |
| Assertiveness | Respect ke saath apni baat rakhna, "na" kehna |
| Independent thinking | Bheed ke bajaye apni soch |
| Critical thinking | Facts check karna, assumptions pakadna |
| Leadership | Pehal karna, doosron ko saath le jaana |
| Self-discipline | Roz lagataar karna |

---

## 1. Shuruaat

### 1.1 Account banana
1. Website kholo, **Get started** dabao.
2. Apna **First name**, **Email** aur **Password** daalo (kam se kam 10 characters).
3. **Create account** dabao.

Koi API key, credit card ya payment nahi chahiye.

### 1.2 Recovery codes (zaroori!)
Signup ke turant baad **10 recovery codes** dikhte hain.
- **Copy all** ya **Download** karke kahin safe rakho (notes app, password manager, ya print).
- Password bhoolne par inhi mein se ek code se naya password banta hai.
- Har code **sirf ek baar** chalta hai. Codes khatam ho jaayein to *Settings → Recovery codes* se naya set banao.
- Phir **I've saved them - continue** dabao.

> Tip: *Settings → Backup security questions* mein do sawaal bhi set kar do. Agar codes bhi kho jaayein, to inke jawab se password reset ho jaata hai.

## 2. Pehla assessment

### 2.1 Length chuno
| Type | Sawaal | Time | Kab chunein |
|---|---|---|---|
| ⚡ **Quick check** | 10 | ~3 min | Jaldi shuru karna hai |
| 🎯 **Standard** (recommended) | 30 | ~7 min | Time aur accuracy ka best balance |
| 🔬 **Deep analysis** | 40 | ~12 min | Sabse sahi profile chahiye |

- Sawaal dete waqt upar **Change length** se type badal sakte ho. Diye hue jawab saved rehte hain.
- Har jawab apne aap save hota hai. Beech mein band karo to wahin se continue hoga.

### 2.2 Sawaal kaise dein
- Wahi jawab do jo aap **asal mein karte ho**, na ki jo karna chahte ho. Koi jawab sahi ya galat nahi hai.
- Kuch sawaal "ulte" hote hain (jaise "Main baad mein baatein yaad karke pareshan hota hoon"). Inme "Almost always" chunne se score kam hota hai. Ye jaan-boojh kar hai, taaki sirf "haan haan" bolkar score na badhe.

### 2.3 Last step: apne shabdon mein
- **90 din ka goal** likho (zaroori).
- **Ek situation jab aapne khud ko roka** (Deep mein zaroori, Quick/Standard mein optional). Jitna sach likhoge, stories aur coach utne personal honge.
- **Finish assessment** dabao. AI aapki profile banata hai (30–90 second).

### 2.4 Aapki development profile
- **Baseline scores:** har skill ka 0–100 score.
- **Summary, Strengths, Growth areas:** AI ka analysis, aapke jawabon par based.
- **Behavioural patterns:** kin aadaton par nazar rakhni hai.
- **90-day roadmap:** teen phases (Foundation, Development, Transformation) ke goals aur milestones.

**Go deeper:** Quick ya Standard kiya hai to **pehle 7 din tak** "Want a more accurate profile?" se sirf naye sawaal dekar Standard ya Deep par ja sakte ho. Scores aur profile zyada jaankari ke saath dobara bante hain. 7 din ke baad starting point lock ho jaata hai, taaki aapki growth sahi naapi jaaye.

> Language: assessment ke upar **English / Hinglish / हिन्दी** chuno. Sawaal aur AI ka content usi bhasha mein aata hai.

## 4. Roz ka session (Today)

### 4.1 Check-in (2–3 min)
1. **Begin check-in** dabao. Sawaal aapke pichhle jawabon aur weak skills ke hisaab se bante hain.
2. Jawab do aur **Submit check-in** dabao. AI ek chhoti **insight** deta hai.

### 4.2 Build today's session
**Build today's session** dabao. AI aaj ke liye ye cheezein banata hai (1–2 minute lagte hain):
- **Introduction:** aaj kya seekhenge aur kyun.
- **Story:** ek lambi kahani (~1300–1600 shabd) jo aapki zindagi jaisi situations par hoti hai. **Begin the story** dabao aur dhyaan se padho.
- Kahani poori padhkar **I've finished reading** dabao. Agar bahut jaldi scroll karke dabaoge, to app "Take your time with the story" bolega. Ye jaan-boojh kar hai.
- **Psychological insights:** kahani mein chhupi psychology.

### 4.3 Interactive scenarios (3)
- Har scenario mein ek option chuno aur **likho kyun** chuna.
- **Submit answer** dabao. AI detailed feedback deta hai: *What worked*, kya behtar ho sakta tha, aur ek better approach.

### 4.4 Real-world challenge
- Ek chhota kaam jo aaj asli zindagi mein karna hai (jaise "meeting mein pehle 5 minute mein bolna").
- Karne ke baad notes likho aur **Mark as done** dabao. Nahi ho paaya to skip bhi kar sakte ho; imaandari se likho.

### 4.5 Reflection
- 3 sawaalon ke jawab do, phir **Complete session** dabao. AI aapke reflection par feedback deta hai.
- Session poora hone par streak badhta hai aur XP milta hai.

## 5. Practice (kabhi bhi)

### 5.1 Decision Lab
1. Area (Career, Relationships, Money, Team...) aur stakes chuno, phir **Generate scenario** dabao. AI ek asli dilemma banata hai.
2. Option chuno, **reasoning** likho, **Commit to decision** dabao.
3. Feedback mein score aur "About your hesitation" milta hai. App ye bhi dekhta hai ki aapne pehla option kitni der mein chuna aur kitni baar decision badla.

### 5.2 Communication Lab
- Exercises ki categories hain: *Expressing opinions*, *Handling disagreement*, *Responding to criticism*, *Setting boundaries*, wagairah.
- **Type** se jawab likho, ya **Voice** se bolkar do. Voice ke liye Chrome, Edge ya Safari chahiye, aur mic ki permission deni hogi.
- Voice mein app aapki **speed (words per minute)** aur **filler words** ("um", "basically", "you know") bhi ginta hai.
- Feedback mein **A stronger version** milta hai: aapki baat ko behtar tarike se kaise kahein.

### 5.3 AI Coach
- Kisi bhi situation ke baare mein chat karo. Coach aapki profile, scores aur progress jaanta hai.
- *Settings → Privacy* mein chaaho to coach ko journal padhne ki permission do. Default mein off hai.

## 6. Growth tracking

### 6.1 Journal
- **New entry** → title + vichaar → **Save entry**.
- Upar search box se purani entries dhoondho.
- Journal **poori tarah private** hai. Friends ko kabhi nahi dikhta.

### 6.2 Progress
- Har skill ka **current score**, **baseline se badlaav**, aur time ke saath **graph**.
- **Score breakdown:** score teen cheezon se banta hai:
  1. **Self-reported:** assessment aur check-ins.
  2. **Demonstrated:** scenarios, Decision Lab aur Communication Lab mein performance (jaise-jaise evidence badhta hai, iska weight badhta hai).
  3. **Consistency:** roz kitna kiya (7 din ke baad, self-discipline par).

### 6.3 Achievements
- **XP aur Level:** har activity ka XP. "How to earn XP" mein list hai.
- **Badges:** jaise First session, 7-day streak, Decision maker, Better together (pehla friend), Race finisher, wagairah.
- **Daily reminder:** time chuno aur calendar file download karo. Phone/Google calendar mein roz ka reminder lag jaata hai.

### 6.4 90-day plan
Teen phases ka plan: **Foundation (din 1–30) → Development (31–60) → Transformation (61–90)**, aur har din ka focus skill.

## 7. Friends

### 7.1 Dost ko invite karna
1. **Friends** → **Create invite link**.
2. **Copy** / **Share** (WhatsApp, etc.) karo, ya **QR code** dikhao.
3. Dost link kholkar **Accept invite** dabata hai. Account nahi hai to wo signup karta hai, aur app mein upar banner se accept karta hai.

Kuch niyam:
- Ek link **5 logon** tak aur **7 din** chalta hai.
- Koi public profile ya search nahi hai. Sirf invite link se hi judte hain.

### 7.2 Friends page
- Har dost ka card dikhta hai: streak, day, level/XP, badges, aur is hafte ke sessions. Ye sab tabhi dikhta hai jab dost ne share karne diya ho.
- **Cheer:** 🔥 💪 🌟 👏 ya ek chhota note (140 characters). Ek din mein ek dost ko 5 aur kul 30 cheers tak bhej sakte ho.
- **Compare:** aap dono ki progress saath-saath. Ye sirf wahi cheezein dikhata hai jo dost share karta hai. "Growth" comparison sabse fair hai, kyunki har koi alag jagah se shuru karta hai.
- **⋯ menu:** Remove friend, **Block** (dono taraf se sab kuch chhup jaata hai), **Report**.

### 7.3 Inbox aur notifications
- Cheers, invite accept aur race invites **Inbox** mein aate hain. Bell par unread number dikhta hai.
- **Turn on notifications** se phone ya computer par bhi notification aata hai.
  - iPhone par pehle app ko Home Screen par add karna padta hai (dekho section 10).

### 7.4 Privacy (Friends → Privacy)
- Aap chuno ki friends kya dekh sakte hain: Activity, XP & level, Badges, Challenges (sirf ginti), Growth, Skill scores, Today's focus.
  - Default mein sirf pehle teen share hote hain.
- **Har circle ke liye alag setting** bhi rakh sakte ho.
- **Pause** se ek click mein saari sharing band ho jaati hai.
- **Kabhi share nahi hota:** journal, assessment ke jawab, check-in moods, coach chats, challenge notes.

## 8. Circles aur Races

### 8.1 Circles (groups)
- **Circles** → naam + icon → **Create circle**.
  - Ek circle mein 30 log tak ho sakte hain. Aap 5 circles ke owner aur 10 mein member ho sakte ho.
- **Board:** sab members ki shared progress, "This week" ya "All-time XP" ke hisaab se.
- **Invite to this circle:** link se log circle mein judte hain (aur aapke friend bhi ban jaate hain).
- Owner/admin members ko remove kar sakte hain, aur owner admin bana sakta hai. **Leave circle** se nikal sakte ho.

### 8.2 Races
- Circle page par (ya friend ke Compare page par) **Start a race** dabao.
  - **5 types:** Streak, Session sprint, Challenge hunt, Check-in race, XP race.
  - **Length:** 3, 7, 14, 21 ya 30 din.
  - **Team race:** joiners do barabar teams mein bante hain.
- Sirf **race ke dauraan** ki activity count hoti hai, isliye sab zero se shuru karte hain.
- **Race privately:** aapka naam "A member" dikhega.
- Race khatam hone par result freeze ho jaata hai, aur "Race finisher" jaise badges milte hain.

## 9. Settings

| Section | Kya kar sakte ho |
|---|---|
| **Profile** | Naam, timezone, **language** (English / Hinglish / हिन्दी) |
| **Privacy** | Coach ko journal padhne ki permission |
| **Your AI** | Default free AI apne aap chalta hai. Chaaho to **OpenRouter se sign in** karo ya apni API key jodo (encrypted save hoti hai) |
| **Password & devices** | Password badlo, baaki devices se sign out |
| **Recovery codes** | Naya set banao (purane band ho jaate hain) |
| **Backup security questions** | Do apne sawaal aur jawab |
| **Your data** | Poora data JSON mein **download** karo |
| **Start the programme again** | "RESET" type karke programme dobara shuru karo |
| **Delete account** | "DELETE" type karke account aur saara data hamesha ke liye delete karo |

### 9.1 Password bhool gaye?
1. Login page par **Forgot password?** dabao.
2. **Recovery code** wala tab: email + ek recovery code + naya password.
3. Ya **Security questions** wala tab: email ke baad aapke sawaal aate hain. Sahi jawab do, phir naya password daalo.
4. Galat koshishon ki limit hai (security ke liye). Thodi der baad dobara try karo.

## 12. FAQ / Problems

| Problem | Hal |
|---|---|
| "AI is busy" / generate nahi ho raha | Free AI kabhi-kabhi busy hota hai. 1–2 minute baad dobara try karo. Settings → Your AI mein apna AI jodne se ye kam hota hai. |
| "Take your time with the story" | Story bahut jaldi khatam ki. Poori padho, phir dabao. |
| Assessment beech mein chhoda | Wapas jao, wahin se continue hoga. |
| Voice button kaam nahi kar raha | Chrome, Edge ya Safari use karo aur mic permission do. |
| Notifications nahi aa rahe | Browser site settings mein notifications allow karo. iPhone par pehle Home Screen par add karo. |
| Friend ka data nahi dikh raha | Shayad unhone sharing pause ki hai ya wo item share nahi kiya. |
| Streak 0 ho gaya | Ek din ka session miss hua. Aaj se dobara shuru karo! |
| Account delete karna hai | Settings → Delete account → "DELETE" type karo. |
